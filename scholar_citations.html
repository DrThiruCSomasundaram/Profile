Notes:

  1. Output Format:
    • Citations are saved in RIS format
    • Each collaborator’s citations are saved in a separate file
    • Files are named using the collaborator’s name (sanitized for file system)
    • All files are saved in the scholar_citations directory
  2. RIS Format Fields:
    • TY: Type of reference
    • AU: Authors
    • TI: Title
    • PY: Publication year
    • JO: Journal
    • N1: Notes (including citation count)
    • ER: End of record
  3. Processing:
    • Handles rate limiting and network errors
    • Skips empty or invalid Scholar IDs
    • Shows progress messages during processing
    • Creates a summary table of results
  4. Usage:
    • The script automatically processes all collaborators from the Excel file
    • Results are saved to individual files
    • A summary table shows the number of publications downloaded for each collaborator
    • Failed processing attempts are logged and displayed
